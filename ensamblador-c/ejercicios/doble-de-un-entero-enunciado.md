# Doble de un entero

Escribe un script bash que genera un programa en ensamblador ARM64 para macOS. El programa lee un entero por stdin con `scanf` y imprime exactamente `doble=N`, donde N es el doble del entero leído.

## Entrada
Una línea con un entero.

## Salida
Una línea con el texto `doble=` seguido del doble del entero y un salto de línea. No se imprime nada más.

## Ejemplo
Entrada: `21`  →  Salida: `doble=42`
