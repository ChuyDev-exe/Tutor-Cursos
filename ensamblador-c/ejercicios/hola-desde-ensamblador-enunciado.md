# Hola desde ensamblador

Escribe un script bash que genera un programa en ensamblador ARM64, lo ensambla, lo enlaza y lo ejecuta. El programa imprime exactamente la línea `Hola desde ensamblador`.

## Entrada
No se lee entrada. El programa no usa stdin.

## Salida
Una sola línea con el texto exacto `Hola desde ensamblador` y un salto de línea final.

## Ejemplo
Entrada: (ninguna)  →  Salida: `Hola desde ensamblador`
