# Sumar con ensamblador en C

Completa el programa C de abajo. La función `suma` debe calcular el resultado con una instrucción de ensamblador ARM64 escrita dentro de C, usando `__asm__ volatile`. El `main` lee dos enteros e imprime `suma=N`.

## Entrada
Una línea con dos enteros separados por un espacio.

## Salida
Una línea con el texto `suma=` seguido de la suma y un salto de línea. No se imprime nada más.

## Ejemplo
Entrada: `3 4`  →  Salida: `suma=7`
