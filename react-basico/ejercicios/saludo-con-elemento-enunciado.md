# Saludo con elemento

Escribe el componente `Saludo` para que devuelva un párrafo con el saludo.

La plantilla ya incluye el mini React (`h` y `renderToString`) y el código que lee la entrada. No modifiques esa parte. Completa solo la función marcada con `TODO`.

## Entrada

Una línea con el nombre de la persona. Puede contener espacios.

## Salida

Exactamente este texto, con el nombre recibido:

`<p id="saludo">Hola, Ana</p>`

No imprimas nada más. El orden de las etiquetas y los espacios importan.

## Ejemplo

Entrada: `Ana`  →  Salida: `<p id="saludo">Hola, Ana</p>`

Entrada: `Ana María`  →  Salida: `<p id="saludo">Hola, Ana María</p>`
