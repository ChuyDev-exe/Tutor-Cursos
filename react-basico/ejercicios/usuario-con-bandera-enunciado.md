# Usuario con bandera

Escribe el componente `Usuario` para que pinte un elemento de lista con clase distinta según la persona esté activa o no.

La plantilla ya incluye el mini React y lee la entrada. No modifiques esa parte. Completa solo la función marcada con `TODO`.

## Entrada

Dos líneas:

1. El nombre de la persona. Puede contener espacios.
2. La bandera `true` o `false`.

## Salida

Si la bandera es `true`:

`<li className="usuario activo">Ana</li>`

Si la bandera es `false`:

`<li className="usuario">Luis</li>`

No imprimas nada más.

## Ejemplo

Entrada: `Ana` + `true`  →  Salida: `<li className="usuario activo">Ana</li>`

Entrada: `Luis` + `false`  →  Salida: `<li className="usuario">Luis</li>`
