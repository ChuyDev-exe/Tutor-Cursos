# 5. Introducción al renderizado 3D con SDL2

En este capítulo aprenderás los conceptos básicos del renderizado 3D usando SDL2. No necesitas una tarjeta gráfica especial; usaremos el renderer software de SDL2 para comprender la proyección y la transformación 3D a 2D.

## Qué aprenderás

- Cómo representar puntos en 3D con coordenadas `(x, y, z)`.
- El concepto de proyección perspectiva: cómo los objetos lejos se ven más pequeños.
- Cómo rotar objetos en 3D usando matrices de rotación simples.
- Cómo transformar coordenadas 3D a la pantalla 2D de SDL2.

## De 3D a 2D: la proyección perspectiva

La fórmula básica para proyectar un punto 3D a 2D es:

```
inv_z = 1 / (z + d)   // d es la distancia de la cámara
x_2d = x * inv_z * factor_escala
y_2d = y * inv_z * factor_escala
```

 donde `d` (distancia de la cámara) y `factor_escala` controlan cuánto "apretado" parece el escena.

## Bucle de renderizado 3D

1. **Definir vertices** — 8 puntos que forman un cubo en 3D.
2. **Rotar vertices** — Aplicar matrices de rotación alrededor de los ejes X e Y.
3. **Proyectar** — Convertir cada punto de 3D a 2D usando la fórmula de arriba.
4. **Dibujar** — Conectar los puntos con líneas o rectángulos en la pantalla 2D.

## Ojos comunes (TDAH-friendly)

- **Todo se ve plano:** Asegúrate de estar usando `z` distinto de 0; sino no hay profundidad.
- **El cubo está invertido:** Si los valores de `z` son negativos y cercanos a 0, la proyección puede verse rara. Prueba con `z = 5` o `z = 10` para que el cubo salga "hacia afuera".
- **Las rotaciones parecen no hacer nada:** Verifica que estés multiplicando por el ángulo correcto (en radianes, no grados). SDL suele trabajar con grados, pero la trigonometría de C usa radianes.
